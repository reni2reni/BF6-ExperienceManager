# BF6 ExperienceManager & 公式プラグイン群

Battlefield Portal (`https://battlefield.com*`) のルールエディタ（Blockly画面）の操作性を大幅に向上させ、外部プラグインを管理・実行できるGoogle Chrome拡張機能および拡張プラグインの総合ドキュメントです。

---

## 1. 本体拡張機能：BF6 ExperienceManager

### 🧩 プラグイン管理 (Plug-in Manager)
* **外部プラグインの導入**: マニフェストURLを指定してプラグインを追加・有効/無効・削除できます（BF2042 Portal Extensions 互換プラグイン対応）。
* **起動モード切り替え**: 起動時に最新コードを自動取得する「自動更新 ON」と、ローカルキャッシュを利用して高速起動する「自動更新 OFF」を切り替えられます。
* **エラー検知**: プラグインの読み込みや実行時にエラーが発生した場合、マネージャー画面上にエラー内容を表示します。

### 🖱️ ブロック操作・右クリックメニューの拡張
* **独自「オプション (Options)」メニュー**: 右クリックメニューの最上部に拡張メニューを追加し、各機能へ素早くアクセスできます。
* **ブロックのコピー / 切り取り / 貼り付け**: ブロックをJSON形式でクリップボードへコピー・貼り付けできます（接続された複数ブロックの構造維持や、サブルーチン名重複時の自動リネームにも対応）。
* **複数ブロック選択**: `Shift + 左クリック` で複数のブロックを選択し、一括コピー・切り取りが可能です。
* **ショートカット操作**:
  * **ダブルクリック**: ブロックの折りたたみ（Collapse）/ 展開（Expand）を切り替え。
  * **ホイールクリック（中クリック）**: ブロックの入力レイアウトを縦並び / 横並び（Inline）に切り替え。
* **メニュー項目の並び替え編集**: 「メニュー編集 ON」を有効にすると、ドラッグ＆ドロップで右クリックメニューの並び順を自由にカスタマイズできます（`Ctrl + Z` / `Ctrl + Shift + Z` で元に戻す・やり直しも可能）。
* **RED Variable**: 変数ブロックの色を視認性の高いダークレッドに変更できます。

### 🖥️ 画面レイアウト・UIの改善
* **Workspace Expand（作業領域の拡大）**: 上部タイトルバーや下部ナビゲーション、購入ボタンなどを非表示にし、ブロック編集エリアを広く確保します。
* **ツールボックスの幅変更・固定表示**:
  * 左側ブロック一覧（Toolbox）の境界線をドラッグして横幅を自由に変更できます（ダブルクリックで初期幅にリセット）。
  * スクロール時も検索バーやヘッダーを上部に固定（Sticky）表示します。
* **表示崩れの自動修復**: 「マイ・エクスペリエンス」一覧ページのヘッダーが一時的に非表示になる不具合を自動で修復します。

## 2. 拡張プラグイン一覧

Plug-in Manager から以下のプラグインを導入することで、さらに高度な編集機能を利用できます。

### 📦 BF6_CODESTOCK（スニペット・ブロックストック管理）
よく使うブロックやロジックの塊（スニペット）を階層フォルダで保存し、いつでもワークスペースへ呼び出せる高機能ストックパネルです。
* **ブロックのワンクリック登録**: 任意のブロックを右クリックして **`CODE STOCK`** を選択すると、ブロックのJSONデータが自動入力された状態で登録画面が開きます。
* **直感的な呼び出し（クリック / ドラッグ＆ドロップ）**:
  * ストック項目を**左クリック**するとワークスペースへ自動配置されます。
  * パネル外へ**ドラッグ＆ドロップ**すると、マウス位置にプレビュー追従しながら好きな場所へ直接配置でき、近くのブロックへ自動スナップ接続します。
* **階層フォルダ管理＆カラー分類**:
  * 最大8×8の「親フォルダ（Parent）× サブフォルダ（Child）」と左側のツリーナビゲーションで整理できます。
  * 8色のカラーラベル（右クリックで色変更可能）による分類・フィルタリング、および「現在タブ内 / 全データ（ALL）」の即時検索に対応しています。
  * 項目名の右クリックでインライン名称変更、ドラッグハンドル（`≡`）で複数選択・並び替え・フォルダ間のコピー＆ペーストが可能です。
* **大容量保存＆バックアップ機能**:
  * IndexedDB と localStorage の併用により大容量データを安全に保持します。
  * 設定メニュー（`⚙️`）から、全データまたは選択タグ単位の **JSONエクスポート / インポート**、**Undo / Redo（最大30回）**、複数タブ間の自動同期設定が行えます。

### 🛠️ BlockUtility（エディタ便利機能）
* **ブロック検索（Block Search）**: 画面左上の虫眼鏡ボタン、または右クリックメニューから検索パネルを開き、ブロック名・変数名・テキスト内容でワークスペース内のブロックを検索・ハイライト移動できます。
* **全体マップ / ミニマップ（Navigate with Minimap）**: 画面左上のマップボタン、または右クリックメニューからワークスペース全体の俯瞰マップを表示します。クリックでの視点ジャンプ、ホイールでのズーム、ドラッグ移動に対応しています（ルールはピンク、サブルーチンはオレンジで色分け表示）。
* **サブルーチン相互ジャンプ**:
  * 呼び出しブロック右クリック → **「サブルーチンへ移動」**（複数ある場合は巡回移動）
  * 定義ブロック右クリック → **「呼び出し元へ移動」**（最も近い呼び出し元へ移動）
* **ルール番号の自動付加**: `modBlock` の右クリックメニュー「ルール番号付加」から、配下の全ルール名に上から順の通し番号（`01:`, `02:`...）を一括付与します。
* **ツールボックスのフォントサイズ変更**: 左側ブロック一覧の上部にフォントサイズ変更バー（10px〜25px）を追加します。
* **ホイールスクロール拡張**: `Shift + ホイール` で横スクロール、`Ctrl + ホイール` で縦スクロールが可能です。

### 📋 Selection_List（選択リスト一括処理・配列生成）
選択リスト（マップ・武器・ビークル等）を持つブロックやルールブロック（イベントタイプ）を右クリックし、`オプション > Selection List ▶` から以下の機能を利用できます。
* **List → ListSelect**: 選択リストの項目を一覧パネルで表示し、検索・複数選択（`Shift` / `Ctrl` クリック）・クリックでの単体/複数ブロックコピーが行えます（`Japanese` プラグイン有効時は日英併記・日本語検索にも対応）。
* **List → array**: リスト内の全項目をグローバル変数配列に格納する `SetVariableAtIndex` ブロック群を自動生成し、256個単位の折りたたみサブルーチンにまとめてクリップボードへコピーします。
* **ListName → array / array (J)**: リストの項目名（または和訳名）をテキスト配列として格納するサブルーチンブロックを生成してコピーします。
* **ListName → File / File (E,J)**: リストの項目一覧（または「英語,日本語」ペア）をテキストファイル（`.txt`）としてダウンロード出力します。

### 🇯🇵 Japanese（日本語化・翻訳支援）
* **ホバー拡大翻訳ポップアップ**: フライアウトやワークスペース上のブロック、ドロップダウン項目にマウスカーソルを合わせると、日本語訳をポップアップで大きく表示します（画面左上の翻訳アイコンボタンでいつでもON/OFF切り替え可能）。
* **ネイティブヘルプの日本語化**: ブロックの「ヘルプ（Help）」ダイアログ内の説明文を自動で日本語に翻訳します。
* **他プラグイン連携**: `Selection_List` の画面・配列・ファイル出力における日本語翻訳エンジンとして連携動作します。
* **キャッシュ＆ブロック一覧出力**: `オプション > 日本語キャッシュ ▶` から、翻訳キャッシュのJSON保存・読み込み、および全ブロックカテゴリ一覧のJSONエクスポートが可能です。

## 3. インストールと初期設定

本拡張機能はChromeの `userScripts` APIを使用するため、インストール後に以下の設定が必要です。

1. Chromeで `chrome://extensions/` を開きます。
2. 右上の **「デベロッパー モード」** をONにします（パッケージ化されていない拡張機能を読み込む場合）。
3. **「BF6 ExperienceManager」** の **「詳細」** ボタンをクリックします。
4. **「ユーザー スクリプトを許可する (Allow User Scripts)」** を **ON** にします。

## 4. ショートカット・操作一覧

| 操作 | 機能 | 提供元 |
| :--- | :--- | :--- |
| `Shift + 左クリック` | ブロックの複数選択 / 解除 | 本体 |
| `ダブルクリック` | ブロックの折りたたみ / 展開 | 本体 |
| `ホイールクリック（中クリック）` | ブロックの内部入力 / 外部入力の切り替え | 本体 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | メニュー編集時の並び順を元に戻す / やり直す | 本体 |
| `Shift + ホイール` | ワークスペースの横スクロール | BlockUtility |
| `Ctrl + ホイール` | ワークスペースの縦スクロール | BlockUtility |
| `パネル外へドラッグ＆ドロップ` | ストックからワークスペースへ直接配置＆自動接続 | BF6_CODESTOCK |
| `ストック項目を右クリック` | スニペット名のインライン変更 | BF6_CODESTOCK |

## 5. ファイル構成

```text
├── manifest.json                 # 拡張機能の設定・権限・スクリプト定義
├── background.js                 # プラグインの取得・キャッシュ管理・Blockly操作ロジック
├── content.js                    # 右クリックメニュー拡張・UI操作・レイアウト調整
├── popup.html / popup.js         # プラグインマネージャー画面のUI・ロジック
├── toolbox-pinned-controls.js    # 左側ブロックメニュー内検索バー等の固定表示処理
├── experiences-display-fix.js    # マイ・エクスペリエンス一覧のヘッダー表示修復
├── icon.png                      # 拡張機能アイコン
└── plugins/                      # 外部プラグイン群（URL経由で読み込み）
    ├── BF6_CODESTOCK.js          # スニペット保存・階層フォルダ・ドラッグ配置
    ├── BlockUtility.js           # 検索・ミニマップ・サブルーチン移動・番号付加
    ├── Selection_List.js         # リスト選択パネル・配列/サブルーチン自動生成
    └── Japanese.js               # ホバー翻訳・ヘルプ翻訳・キャッシュ管理
```
