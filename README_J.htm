1. 本体拡張機能（BF6 ExperienceManager） BF2042 Portal エディタの操作性を根本から改善し、各種プラグインを管理・動作させるための基本エンジンとなる拡張機能です。 主な機能 プラグインマネージャー 各種プラグイン（BlockUtilityなど）の追加、ON/OFF切り替え、一括管理。 自動更新ボタン（↻）：ONにすると本体拡張起動時にプラグインを最新コードに自動更新。OFFにするとキャッシュ起動で超高速で起動します。 ブロックのコピー・切り取り・貼り付け 右クリックメニューからのコピー/切り取り/貼り付けに対応。 Ctrl+V 貼り付け：貼り付け位置が現在のマウスカーソル位置に追尾します。 複数ブロック一括貼り付け：複数選択して貼り付けた場合も、1回の「元に戻す（Ctrl+Z）」でまとめて消去可能。 Shift ＋ クリックによる複数ブロック選択 離れたブロックや複数のブロックを Shift クリックで水色に同時選択し、一括コピー・移動が可能。 マウスショートカット操作 ダブルクリック：ブロックの「折りたたみ / 展開」を即座に切り替え。 ホイールクリック（中央クリック）：ブロックの入力を「縦並び / 横並び」に即座に切り替え。 右クリックメニューの並び替え・ダークテーマ化 右クリックメニューの「メニュー編集 ON」にすると、各項目の「☰」をドラッグして好みの順番に並び替え可能（保存・リセット・Ctrl+Z対応）。 眩しくないダークテーマ表示に統一。 作業スペースの最大化（Workspace Expand） 画面上部の大きなタイトルバー、画面下の不要なフッターパネル、右側の「購入」ボタンなどを非表示にして、ブロック編集画面を広く使えます。 左ブロックリスト（Toolbox）の横幅ドラッグリサイズ 左側のブロック一覧パネルの境界線をマウスドラッグで自由に広げたり縮めたりできます（ダブルクリックでリセット）。 RED Variable（濃い赤色の変数ブロック） 通常の薄い赤色から視認性の高い濃い赤色に切り替え可能。 2. BlockUtility（プラグイン） ブロックの検索、長大なルールの整理、画面内の高速移動など、日々のロジック作成作業を劇的に快適にする便利ツール集です。 主な機能 全体縮小ミニマップ（Minimap） 画面全体のブロック配置を小窓に俯瞰表示。 ミニマップ上をクリックするとそのブロック位置へ一瞬でカメラがジャンプ。 マウスホイールでミニマップ自体の拡大・縮小、外周付近でオートスクロール。 ホバーした位置にあるブロックの名前（ルール名・サブルーチン名）を情報バーに大きく表示。 ブロック内テキスト高速検索（Block Search） 画面上の全ブロックから、指定したキーワード（変数名、サブルーチン名、テキストなど）を検索。 該当ブロックへ自動でスクロールし、水色の光彩ハイライトで場所を強調表示（Enterで次の候補へ巡回）。 サブルーチン相互ジャンプ サブルーチン呼び出し側を右クリック → 「サブルーチンへ移動」で定義元へジャンプ。 サブルーチン定義元を右クリック → 「呼び出し元へ移動」で呼び出しブロックへジャンプ（複数ある場合は順に巡回）。 ルール番号の一括付加・整列 MODブロックを右クリックして実行すると、内包されているルールブロックに上から順に 01: 02: 03: と通し番号を自動付与して名前を整理。 左ブロックリストの文字サイズ変更（◀ 20px ▶） 左パネルの一番上にコントローラーが表示され、文字の大きさと行間をワンクリックで切り替え可能（10px / 15px / 20px / 25px）。 プラグインをOFFにすれば元のポータル標準サイズに完全リセット。 マウスホイールによる画面スクロール Shift ＋ ホイール：画面を左右にスクロール。 Ctrl ＋ ホイール：画面を上下にスクロール。 3. JapaneseBF6PORTAL（プラグイン） 英語表記のままになっているブロックや説明文を、自然で分かりやすい日本語に翻訳・ローカライズするプラグインです。 主な機能 ブロック名・テキストの完全日本語化 公式では英語のまま残っているブロック名、関数名、パラメータ名を分かりやすい日本語に置換表示。 検索エイリアスの日本語対応 左のブロック検索バーで「キル」「プレイヤー」「ベクトル」「ダメージ」などの日本語を入力しても、該当する英語ブロックがしっかりヒットするように検索をサポート。 右クリックメニュー・各種注釈のローカライズ エディタ内の各種英語メッセージや右クリックメニューの英語表記を、Portalユーザーに馴染みのある表現に統一。 4. Selection_List（プラグイン） 武器、ビークル、マップ、イベントタイプなど、ドロップダウン選択肢（リスト）を持つブロックから、項目を自由自在に抽出・配列化・コピー・ファイル出力できる強力なデータ抽出プラグインです。 ■ 使い方（起動方法） ドロップダウンリストを持つブロック（各種アイテムブロックやルールブロックなど）を右クリックし、「オプション >」 の中にある 「Selection List ▶」 にマウスを合わせると専用メニューが開きます。 ■ 主な機能一覧 1. List → ListSelect（専用選択ウィンドウ） ドロップダウンの中身を一覧パネルとして画面上にポップアップ表示します。 キーワード検索：たくさんの項目の中からインクリメンタルサーチですぐに見つけ出せます。 ワンクリック即コピー： リスト内の項目をクリックするだけで、その項目が選択された状態のブロックがクリップボードへコピーされます。あとは画面上で貼り付けるだけです。 複数一括選択＆コピー： Shift ＋ クリック：範囲まとめて選択。 Ctrl（MacはCmd）＋ クリック：複数項目を個別に複数選択。 「Copy selected」を押すと、選んだ全アイテムのブロックが一瞬でまとめてクリップボードへコピーされます。 日/英のバイリンガル表示（Japaneseプラグイン連動）： 「日本語 | 英語」表記と「英語 | 日本語」表記をワンクリックで切り替え可能。 ウィンドウの自由操作： タイトルバーをつかんでドラッグ移動。 右下の斜線部分をつかんで自由に拡大・縮小（サイズと位置は自動保存されます）。 タイトルバーをクリックすると邪魔にならないように小さく折りたためます。 2. List → array（全項目の配列サブルーチン一括生成） ドロップダウンにあるすべての項目を配列（Array）に格納する処理を自動生成し、クリップボードにコピーします。 項目数が多い場合も自動的に256個ずつ分割し、折りたたまれたサブルーチン（SUB_MAP_01 など）として綺麗にまとめてくれます。 「マップ一覧配列」や「武器一覧配列」などを手作業で作る必要がなくなります。 3. ListName → array（項目名の文字列配列生成） アイテムそのものではなく、**項目の名前（テキスト文字）**をテキスト配列として格納するサブルーチンを自動生成し、コピーします。 4. ListName → array (J)（※Japaneseプラグイン連動） 項目名を自動で日本語に翻訳したテキスト配列としてサブルーチンを生成し、コピーします。 ゲーム内メッセージやHUDに日本語でアイテム名を表示させたいときに便利です。 5. ListName → File（テキストファイル出力） ブロックに含まれる全項目の一覧を、PC上にテキストファイル（します。 メモ帳やExcelでリストを確認・管理したいときに役立ちます。 6. ListName → File (E,J)（※Japaneseプラグイン連動） 全項目を**「英語名, 日本語名」のCSV形式**でテキストファイルに出力します。 外部ツールで翻訳対照表を作ったり、一覧表を作成する際に便利です。 ■ 対応している主なブロック 各種 Item ブロック：MapsItem（マップ）、WeaponsItem（武器）、VehiclesItem（乗り物）など、ドロップダウンを持つすべてのアイテムブロック。 Rule ブロック：ルールブロックの「EVENTTYPE（トリガーイベント一覧）」の抽出・リスト化にも対応しています。

📖 Code Stock プラグイン 取扱説明書 Code Stock は、Battlefield 2042 Portal のルールエディタ上で、よく使うブロックコード（スクリプト）を階層管理していつでもワークスペースへ呼び出せるスニペット管理プラグインです。 🚀 主な機能と使い方 1. ブロックの登録（保存） ワークスペースから直接登録： エディタ上のブロックを右クリック ➔ [CODE STOCK] を選択すると、そのブロックのデータが入力欄に入った状態でパネルが開きます。 名前を付けて [ADD] を押すと登録されます。 手動登録： パネル上部の [≡ NEW ENTRY ≡] をクリックし、名前とコード（JSON）を入力して [ADD] を押します。 2. ブロックの配置（取り出し） ドラッグ＆ドロップ配置： リスト内のアイテム名をつかんでワークスペース上へドラッグし、指を離した場所へブロックを配置します。 近くに接続可能なブロックがある場合、自動的にスナップ接続されます。 クリック配置： アイテム名を1回クリックするだけで、エディタ上の空きスペースへ即座に貼り付けられます。 3. タブ・カテゴリ管理（階層分け） 親カテゴリ（A, B, C...）と子サブカテゴリ（A-1, A-2...）の2階層で整理できます。 タブの切り替え： 上部の横並びタブ、または左側のツリーメニュー（TAB▼）をクリックして切り替えます。 タブ名・文字色の変更（右クリック）： タブを右クリックするとメニューが開き、名前の変更、フォルダごとのコピー＆ペースト、文字色の変更ができます。 左ツリーの幅調整： ツリーとリストの境界線（縦のバー）をドラッグして、ツリー幅を自由に伸縮できます。 4. 検索機能 ALL / TAB 切り替えボタン： [TAB]：現在開いているタブの中だけを検索します。 [ALL]：全タブに登録されているすべてのコードから横断検索します（検索結果には所属タブ名が表示されます）。 入力したキーワードはタブを切り替えても保持され、右側の [✕] または BackSpace で消去するまで残ります。 5. リストの編集・整理 直接名称変更： リスト内のアイテム名を右クリックすると、その場で名前を直接書き換えられます（Enterで確定、Escでキャンセル）。 並び替え（ドラッグ）： 左端の ≡ マークをつかんで上下にドラッグ＆ドロップすると、表示順を入れ替えられます。 複数選択操作： ≡ をクリック（ShiftやCtrlキー併用可能）して複数選択し、右クリックメニューから一括コピー・切り取り・削除が可能です。 色分け： 8色のカラーパレットから好きな色を選んで、スニペットごとにラベルカラーを設定できます。 6. パネルの操作・ツールバー ボタン 機能説明 🐛JS Stock ▼ タイトルバーをドラッグでパネル移動。クリックで最小化/復元。 ↩️ / ↪️ Undo / Redo（直前の操作を元に戻す／やり直す。最大30回）。 ⚙️ (設定) データの全体バックアップ（Export/Import）、選択中タグのみの書き出し、カテゴリ数の増減（最大8×8）。 🔒️ / 🔓️ ピン留め。ロック時はパネルが常に画面に残り、アンロック時は配置後に自動で閉じます。 ◀ 15px ▶ リストとツリーの表示フォントサイズ変更（12px〜30px）。最小の12pxにすると上下の余白が詰まり、一覧性がアップします。 CodeLists (X/Y) （現在の選択タブ内登録数 / 全体の総登録数）をリアルタイム表示。 7. データのバックアップと同期 自動保存： 登録・変更した内容はブラウザ内（IndexedDB / localStorage）に自動保存されます。 手動バックアップ（推奨）： ⚙️（歯車アイコン） ➔ [EXPORT] を押すと、全データを JSON ファイルとしてPCに保存できます。ブラウザのキャッシュクリア等に備えて定期的にバックアップを取ることを推奨します。 同期（同期チェックボックス）： ⚙️メニュー内の「同期」を ON にすると、複数のタブやウィンドウでエディタを開いている際に最新データを自動共有します。
